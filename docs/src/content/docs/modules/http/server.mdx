The `http.server` module emits a message for every HTTP request that is made to the server.

<SchemaInfo type="module" id="http.server"></SchemaInfo>

### Example

Start an HTTP server listening on port 3000

```yaml
- id: httpServer
  type: http.server
  params:
    port: 3000
```
