The `sqlite.client` module can open/create SQLite databases

<SchemaInfo type="module" id="sqlite.client"></SchemaInfo>

This module implements the `DatabaseModule` interface.


### Example

Opens an in-memory SQLite database

```yaml
- id: myDatabase
  type: sqlite.client
  params:
    dsn: ":memory:"
```
