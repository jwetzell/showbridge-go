This processor will create a MIDI Note On message with the specified channel, note, and velocity.

<SchemaInfo type="processor" id="midi.note_on.create"/>

### Example

```yaml
- id: create
  type: midi.note_on.create
  params:
    channel: "1"
    note: "60"
    velocity: "127"
```
