This processor will send a MIDI Note Off message with the specified channel, note, and velocity.

<SchemaInfo type="processor" id="midi.note_off"/>

### Example

```yaml
- id: send
  type: midi.note_off
  params:
    module: midi-out
    channel: "1"
    note: "60"
    velocity: "127"
```
